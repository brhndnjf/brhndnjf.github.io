# brhndnjf.github.io

Situs pribadi. Statis sepenuhnya — tanpa backend, tanpa build step.

- Beranda: <https://brhndnjf.github.io>
- Aplikasi latihan SKD: `/skd/` (menyusul)

## Struktur

```
index.html      beranda
.nojekyll       mematikan pemrosesan Jekyll
404.html        halaman tidak ditemukan (menyusul)
assets/         css, js, gambar (menyusul)
skd/            aplikasi latihan SKD (menyusul)
```

## Catatan

Semua konten disajikan apa adanya dari branch `main`. Tidak ada rahasia di repo ini —
apa pun yang ada di sini bisa dibaca publik, termasuk kunci API bila ditambahkan.
